# 🧲 Magnetium

![Minecraft Version](https://img.shields.io/badge/Minecraft-1.21.11%2B-brightgreen)
![Mod Loader](https://img.shields.io/badge/Loader-Fabric-blue)
![License](https://img.shields.io/badge/License-MIT-yellow)

Magnetium is a lightweight and highly configurable Minecraft mod that adds magnets to automatically pull dropped items towards the player within a specified range.

No more wasting time manually picking up blocks after intensive mining or farming sessions!

## ✨ Features

* **🧲 Magnet Tiers:** From basic magnets to advanced versions featuring extended reach.
* **🔨 Magnetic Hammer:** Destroys a 3x3 block area and automatically picks up dropped items.

## 📦 Installation

1. Make sure you have the correct Mod Loader installed (**Fabric**).
2. Download the appropriate version of **Magnetium** for your Minecraft version.
3. Place the downloaded `.jar` file into your `mods` folder.
